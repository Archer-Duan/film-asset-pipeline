# Contributing

Thank you for helping improve Film Asset Pipeline.

1. Create a focused branch from the default branch.
2. Never use copyrighted film frames, real API credentials, or paid generated assets as fixtures.
3. Install the development environment with `python -m pip install -r requirements-dev.txt`.
4. Run `python -m pytest -q` and `python -m ruff check src tests` before opening a pull request.
5. Describe user-visible behavior, migration impact, API cost impact, and test coverage in the pull request.

Bug reports should include the application version, Python version, operating system, sanitized logs, expected behavior, and reproduction steps. Remove request IDs or account details when they could identify a private account.
